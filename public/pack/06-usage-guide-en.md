# Scope Creep Shield Kit — Usage Guide (EN)

A practical order of operations from Glint. Use what fits your practice; adapt the [BRACKETS].

## 10-minute setup

1. Duplicate the **Scope of Work** template and fill deliverables, fee, and assumptions before you send a quote.  
2. Attach or paste the **Exclusions checklist** — check every item that is out of scope.  
3. Add the **Revision limits policy** (usually 2 rounds) to your proposal or kickoff email.  
4. Save the **Change order** template in your docs folder so you can send it the same day a request appears.  
5. Star the **Client scripts** file for “one more thing”, AI-discount, and change-order messages.  
6. Open the **Change request tracker** CSV and log every informal ask (even if you say yes for free once — visibility matters).

## When a client asks for “just one more thing”

1. Pause. Do not start the work in the same reply.  
2. Map the ask to the SOW: in-scope revision vs new deliverable.  
3. If new: send script #1 + a filled change order (script #3).  
4. Log the row in the tracker (date, ask, decision, fee, status).  
5. Only schedule work after written approval.

## When someone asks for an “AI discount”

Use script #2. Offer a **smaller scope**, not a lower rate for the same work. Your judgment and delivery risk are the product.

## Weekly hygiene (15 minutes)

- Review open change requests in the CSV.  
- Close stale asks (“deferred to Phase 2”).  
- Update remaining revision rounds per active project.

## Mindset

Scope is a product feature. Clear boundaries protect the client’s timeline as much as your margin.

— Glint
